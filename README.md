# Baza wiedzy Eteryu.space

Oficjalne repozytorium technicznej bazy wiedzy dotyczącej prywatności oraz cyberbezpieczeństwa.

Znajdziesz tutaj kody źródłowe całej dokumentacji, skrypty oraz utwardzone konfiguracje bazujące na sprawdzonych rozwiązaniach i architekturze Zero Trust. Głównym celem projektu jest dostarczenie konkretnych metod redukcji ryzyka oraz odzyskania kontroli nad cyfrową tożsamością.

Jeśli napotkasz jakiekolwiek problemy z wdrożeniem naszych zaleceń lub masz ogólne pytania, śmiało utwórz nowy wątek w zakładce [Discussions](https://github.com/Eteryu404/docs.eteryu.space/discussions). 
Jeśli chcesz zasugerować poprawkę, zgłosić błąd lub dodać nowy materiał, po prostu otwórz [Issue](https://github.com/Eteryu404/docs.eteryu.space/issues).
Możesz również skontaktować się ze mną bezpośrednio na [Mastodonie](https://infosec.exchange/@eteryu).

Wszystkie pliki zawarte w tym repozytorium są udostępniane na licencji [MIT](https://opensource.org/licenses/MIT).
